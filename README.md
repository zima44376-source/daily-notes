# 每日手记

一个适合手机和电脑浏览器使用的私人每日记录网页。无需账号或后端服务。

## 功能

- 每日任务：添加、完成、删除，并为未完成任务写原因备注。
- 学习记录：每天最多三项，每项记录主题、时长、收获和下一步；多项时可折叠查看摘要。
- 每日反思：每天最多三项，每项记录做得好的事、困难和明天的调整；多项时可折叠查看摘要。
- 在月历中查看今天及以前的记录，有内容的日期带圆点标记；内容输入后自动保存。
- 导出、导入 JSON 备份。

## 使用

用浏览器打开 `index.html`，或将本目录中的 `index.html`、`styles.css`、`calendar.css`、`calendar.js`、`app.js` 一起部署为静态网站。GitHub Pages 可以直接托管这些文件。

记录保存在当前浏览器的 `localStorage` 中。同一个网站在不同设备上的数据不会自动同步。更换设备、清除浏览器数据或更改网站地址前，请从页面右上角导出备份，再在目标设备导入。导入会覆盖目标浏览器中的现有记录。
